# Chapter 12: Ratios Run the World

## The core idea

A ratio is a comparison, and the order states the question. The bottom amount is what counts as one, so always name it first: which package, which whole, which base, which unit. A percent is a ratio per hundred of a named whole. Percent changes are scales tied to a base, so successive changes multiply their factors rather than cancel. A unit rate (price per ounce) divides each total by its own amount so two sizes answer the same question.

## Key equations (as the chapter writes them)

- 18 oz / 12 oz = 3/2, and 12 oz / 18 oz = 2/3
- 3/4 = 75/100 = 75%
- 100 x 1.20 x 0.80 = 96, and 1.20 x 0.80 = 0.96
- $4.50 / 18 oz, with 450 / 18 = 25 and 324 / 12 = 27 cents per ounce

## Coaching method

1. Ask for the learner's own comparison (two package sizes, a survey, a price change).
2. Predict first: "Which amount is the measuring stick? Will the ratio be above or below 1?"
3. Walk one substitution at a time: write amount over amount with units, cancel the unit, simplify, then say it in words ("A holds 3/2 of one B").
4. Check with a reverse step: multiply back (0.75 x 24 = 18; 18 x 25 = 450).
5. For percent changes, always ask "percent of what?" at each step.

## Common sticking points

- Flipping the ratio and not noticing the meaning changed. Say the question aloud: "A compared with B".
- Treating up 20% then down 20% as cancelling. The second 20% is of 120, not 100.
- Percent of the wrong whole: 18 is 75% of 24 but 90% of 20.
- Working in dollars with decimals. Switch to cents; 450 / 18 is easier than 4.50 / 18.
- Comparing totals instead of per-one prices.

## Worked example with the book's numbers

Which is cheaper per ounce: Label A, 18 oz for $4.50, or Label B, 12 oz for $3.24?
1. Work in cents: $4.50 = 450 cents, $3.24 = 324 cents.
2. A: 450 / 18 = 25 cents per ounce.
3. B: 324 / 12 = 27 cents per ounce.
4. 25 is less than 27, so Label A is lower per ounce.
5. Reverse: 18 x 25 = 450 and 12 x 27 = 324. Both match.

Up then down: start 100. 20% of 100 = 20, so 100 + 20 = 120. 20% of 120 = 24, so 120 - 24 = 96. One line: 100 x 1.20 x 0.80 = 96, which is 4 below the start.

## When the idea stops working

- Ratios of amounts in different units need a change of units first.
- A zero bottom amount is not allowed.
- Part-to-part ratios (2 concentrate to 3 water) need the total as the whole before becoming a percent.
- Lower unit price is not the same as a good buy; the labels in the chapter are made-up.
