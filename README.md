# Math Class Didn't Show Its Work: companion notebooks and skills

Companion material for *Math Class Didn't Show Its Work* by Jason Karpeles. Each chapter has a
Jupyter notebook that reproduces its calculations and figures, and a skill
that an AI assistant can use to teach the chapter.

Interactive version: https://karpeles.com/companions/math-class-didnt-show-its-work/
About the book: https://karpeles.com/publishing/math-class-didn-t-show-its-work

## What is here

- `notebooks/`: one notebook per chapter, already run, so the results show on GitHub.
- `skills/`: a master skill for the book and one skill per chapter.

## Run the notebooks

You need Python 3.10 or later.

    pip install -r requirements.txt
    jupyter lab

Open any notebook in `notebooks/` and choose Run All.
