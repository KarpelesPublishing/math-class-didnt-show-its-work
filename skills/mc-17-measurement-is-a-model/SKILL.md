# Chapter 17: Measurement Is a Model

*Math Class Didn't Show Its Work* by Jason Karpeles. Chapter idea: a number without a unit is not wrong, it is unfinished. A measurement keeps the number, the unit and the model together.

## The core idea in plain words

- A decimal product is a whole-number product in disguise. 3.2 is 32 tenths and 1.8 is 18 tenths, so multiply 32 by 18, then divide by 100 (tenths times tenths is hundredths).
- Before multiplying two lengths, put them in the same unit. Convert each side once.
- The boundary (perimeter, in meters) and the interior (area, in square meters) have different jobs. They cannot be ranked against each other.
- A calculated result and its rounded display are not the same thing. Keep the exact value for later work; label the rounded one where it is shown.

## Key equations (as the chapter writes them)

- 32 x 18 = 32(10 + 8) = 320 + 256 = 576
- 1 m² = (100 cm)(100 cm) = 10,000 cm²
- A = lw and P = 2l + 2w
- 5.76 m² ≈ 5.8 m²

## Coaching method

1. Ask for the learner's own numbers (a room, a mat, a recipe, a calculator result that looked odd). Use theirs before the book's.
2. Have them predict first: "Roughly, should the answer be bigger or smaller than 6? Between which two whole numbers?"
3. Walk the calculation one substitution at a time. Write each line with the real numbers in it, for example "32 x 18 = 32(10 + 8) = 320 + 256 = 576". Never skip to the result.
4. Check with a reverse or second route: estimate the band, redo in the other unit, or divide back.
5. Ask them to say in their own words what the unit means (meters, or square meters).

## Common sticking points

- "Where does the point go?" Count tenths: one place in each factor means two places in the product. Then run the estimate; 57.6 and 0.576 fail it.
- "Why 10,000 and not 100?" Area uses two directions, so the 100 is used twice. A grid of 10 cm squares helps them see it.
- "Why does my room have a big perimeter but small area?" Different jobs: edging is bought by the meter, flooring by the square meter.
- "Is 5.8 wrong then?" No. It is a display of 5.76. Nothing about the calculation changed.

## Worked example with the book's numbers

Decimal product, 3.2 x 1.8:
- Whole numbers: 32 x 18 = 32(10 + 8) = 320 + 256 = 576.
- Place the point: 576 / 100 = 5.76.
- Estimate: 3.2 x 1 = 3.2 and 3.2 x 2 = 6.4, so the answer is between 3.2 and 6.4. 5.76 fits; 57.6 and 0.576 do not.

Mixed units, a mat 1.5 m by 80 cm:
- Convert: 80 / 100 = 0.8 m.
- Area: 1.5 x 0.8 = 1.20 m².
- Check in centimeters: 150 x 80 = 12,000 cm², and 12,000 / 10,000 = 1.20 m².
- Perimeter: 2(1.5 + 0.8) = 4.6 m.

Boundary and interior, a 3.2 m by 1.8 m room:
- P = 2(3.2) + 2(1.8) = 6.4 + 3.6 = 10.0 m.
- A = 3.2 x 1.8 = 5.76 m². A 2.5 m by 2.5 m room has the same 10.0 m perimeter but 6.25 m².

Rounding 5.76 to the nearest tenth:
- 5.76 - 5.7 = 0.06 and 5.8 - 5.76 = 0.04, so 5.76 is nearer 5.8. Display ≈ 5.8 m²; the exact value stays 5.76 m².

## When the idea stops working

- The tenths trick shown here assumes one decimal place per factor. With two places in a factor, divide by ten once more.
- Area formulas here assume a flat rectangle with square corners.
- Rounding of a display says nothing about how precisely a real length was measured.
- A value exactly halfway (like 5.75) needs a stated tie rule.
