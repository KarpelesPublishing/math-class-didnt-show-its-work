# Chapter 5: How Big Is It?

*Math Class Didn't Show Its Work* by Jason Karpeles

## The core idea in plain words

Size comes from place. A digit's value depends on its row, and one row to the left is worth ten times as much. A grouping tells you what gets repeated, so it changes the question, not just the answer. An estimate is useful only when you say what you changed and which way that change pushes the result.

## Key equations (as the chapter writes them)

- Place value: $5{,}084{,}000 = 10 \times 508{,}400$
- Grouping: $6+4\times3 = 18$ and $(6+4)\times3 = 30$
- Theater: $18 \times (30 - 2) = 504$
- Tiles: $13 \times 19 = 13 \times (20 - 1) = 247$

## Coaching method

1. **Ask for the learner's own numbers.** Two numbers from their bank statement, a price list, or a seating plan work well. Use the book's numbers only if they have none.
2. **Have them predict first.** "Which place do you think will decide it?" or "Will the estimate come out high or low?" A wrong guess is useful information, never a failure.
3. **Walk one substitution at a time.** Line digits up under place names. Write each step on its own line, for example 18 x 28 = 18 x (30 - 2) = 540 - 36 = 504.
4. **Check with a reverse step.** Subtract the two numbers and see that the sign agrees with the comparison. Check a product by a different route (round up and compensate, or split the other factor).

## Common sticking points and gentle ways through

- **"The longer-looking number must be bigger."** Line the digits up by place, not by first digit. Ask: which row is the first one that differs, reading from the left?
- **"Why not just go left to right?"** Say what each part means in words: "six, plus three groups of four." The words show what is repeated.
- **"Rounding is cheating."** It is fine when you write down what moved. Put an arrow beside each rounded factor: up, down, or kept.
- **Mixed arrows.** If one factor went up and one went down, say out loud that the direction is not settled, then compute exactly.

## Worked example with the book's numbers

Which is larger, 5,084,000 or 508,400?

1. Line up: 5,084,000 has digits 5, 0, 8, 4, 0, 0, 0 (millions to ones). 508,400 has digits 0, 5, 0, 8, 4, 0, 0.
2. First row from the left that differs: millions, where 5 is more than 0. So 5,084,000 is larger.
3. Check by subtraction: 5,084,000 - 508,400 = 4,575,600, positive, so it agrees.
4. Bonus: every digit sits one place left of its partner, so 10 x 508,400 = 5,084,000.

Estimating the theater (18 rows of 28 seats) as 20 x 30:

1. Estimate: 20 x 30 = 600. Both factors moved up, so predict high.
2. Exact: 18 x 28 = 18 x (30 - 2) = 540 - 18 x 2 = 540 - 36 = 504.
3. Miss: 600 - 504 = 96 seats high.

For the tile display (13 rows of 19) estimated as 10 x 20: 10 went down, 20 went up, so the direction is not settled. Exact: 13 x (20 - 1) = 260 - 13 = 247. Estimate 200, so 247 - 200 = 47 low.

## When the idea stops working

- Place comparison needs numerals lined up by place and carrying the same units.
- Order of operations here covers groups, multiplication, addition, with no exponents.
- The up/down arrow rule needs positive factors and says nothing about how big the miss is. It fails for mixed directions.
