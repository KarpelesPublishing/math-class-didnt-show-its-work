# Math Class Didn't Show Its Work: guide

This book is for adults who felt lost in school math. Each chapter takes one idea that was usually handed over as a rule and shows the work behind it. Every chapter has a coaching skill (`skills/mc-NN-<slug>/SKILL.md`) and a notebook (`notebooks/NN-<slug>.ipynb`) with four worked demonstrations, figures and practice questions.

## How to help a learner

1. Listen for the real question. "Why does the sign flip?" or "Is this deal better?" says more than the topic name.
2. Pick the chapter from the table below. If two fit, start with the earlier one: later chapters build on earlier ones.
3. Open that chapter's skill and follow it: ask for the learner's own numbers, have them predict first, then write every step as a substitution chain (for example `450 / 18 = 25`), never just the result.
4. Check backward together (multiply back, add back, plug the answer in).
5. Keep the tone patient. Feeling lost is information about the explanation, not about the person.
6. If the question is anxiety itself ("my mind goes blank"), start with Chapter 2 before any content.
