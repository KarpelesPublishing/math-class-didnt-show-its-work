# Chapter 10: Common Units Explain the Rules

## The core idea

Adding means counting. You can only add counts of the same kind of thing: fifths with fifths, dollars with dollars. The denominator names the unit, the numerator counts it. So the bottom number stays when you add like parts, and when the parts differ you first cut both into a smaller shared unit (a common denominator), then add the counts. Decimal places are the same story: the first place counts tenths, the second counts hundredths, which is why the points must line up.

## Key equations (as the chapter writes them)

- 2/5 + 1/5 = 3/5, and 2/5 + 1/5 is not 3/10
- 1/3 + 1/4 is not 2/7
- 1/3 + 1/4 = 4/12 + 3/12 = 7/12
- 1/3 + 1/4 = 8/24 + 6/24 = 14/24
- 3/4 + 2/3 = 9/12 + 8/12 = 17/12
- 0.3 = 3/10 = 30/100
- 0.35 + 0.20 = 35/100 + 20/100 = 55/100

## Coaching method

1. Ask for the learner's own sum (a recipe, a measurement, a price).
2. Predict first: "Should the answer be bigger or smaller than 1? Roughly where?"
3. Say the unit out loud before any arithmetic: "fifths plus fifths". Then walk one substitution at a time: rename each piece in the shared unit, show the multiplication on top and bottom, add the counts, keep the unit.
4. Check with a reverse step: subtract one piece from the total and see the other piece return, or compare decimals (7/12 = 0.583 versus the claimed 2/7 = 0.286).
5. Ask: "Did both pieces come from the same whole?"

## Common sticking points

- Adding tops and bottoms (1/3 + 1/4 = 2/7). Show that 2/7 is about 0.286 but the pieces already cover about 0.583 of the pan. A sum that is smaller than one of its pieces cannot be right.
- Not knowing which common unit to choose. Any common multiple works; list multiples of both bottoms and pick a shared one. The smallest keeps counts short.
- Unease at answers above 1. 17/12 is a valid amount: 17 = 1 x 12 + 5, so 1 5/12.
- Decimals: "just line up the right edges". Line up the points so tenths meet tenths.

## Worked example with the book's numbers

Add 3/4 + 2/3.
1. Estimate: three fourths plus more than one half must pass 1.
2. Common unit: twelfths fit in both 4 and 3 (4 x 3 = 12).
3. 3/4 = (3 x 3)/(4 x 3) = 9/12.
4. 2/3 = (2 x 4)/(3 x 4) = 8/12.
5. 9/12 + 8/12 = 17/12.
6. 17 = 1 x 12 + 5, so 17/12 = 12/12 + 5/12 = 1 5/12.
7. Reverse: 1 5/12 = 12/12 + 5/12 = 17/12, and 17/12 - 8/12 = 9/12 = 3/4. Matches.

Decimal case: 0.35 + 0.20 = 35/100 + 20/100 = 55/100 = 0.55 (tenths 3 + 2 = 5, hundredths 5 + 0 = 5).

## When the idea stops working

- Both pieces must be parts of the same whole. A fifth of a small pan and a fifth of a large pan are different amounts.
- Matching bottoms is only the start; a shared unit must fit evenly in both.
- The decimal grid picture assumes at most two places; the same idea extends to more places by naming a finer unit.
