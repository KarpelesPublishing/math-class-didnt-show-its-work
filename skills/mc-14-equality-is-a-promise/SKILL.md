# Chapter 14: Equality Is a Promise

## The core idea

An equals sign claims that two sides have the same value. It can be true for some inputs and false for others. Solving keeps that promise one equal change at a time, and every answer is checked in the original line. An inequality works the same way, with one exception: multiplying or dividing by a negative number reflects every point across zero, so the comparison sign must turn around.

## Key equations (as the chapter writes them)

- 3x + 5 = 20, with candidates 2, 5, 7 giving left sides 11, 20, 26
- 3x + 5 - 5 = 20 - 5, so 3x = 15, then (3x) / 3 = 15 / 3, so x = 5
- 5x - 7 = 2x + 8, which becomes 3x - 7 = 8
- -2x + 3 <= 11, which gives x >= -4

## Coaching method

1. Ask for the learner's own equation, or use a price or invoice they know.
2. Predict first: "If I try this number, will the left side be too big or too small?"
3. Walk one substitution at a time: write the operation on both sides before shortening the line.
4. Check with a reverse step: put the answer back into the original equation and evaluate each side separately.
5. For inequalities, test the boundary and one value on each side of it.

## Common sticking points

- Doing a step to one side only. Use the balance: take 5 from both pans or neither.
- Believing nothing can happen across the equals sign "by itself". Each move is an operation on both sides.
- Subtracting 2x feels illegal because x is unknown. It is fair: both sides lose the same amount, so the gap between them does not change.
- Forgetting the flip when dividing by a negative. Remember 2 < 5 but -2 > -5.
- Flipping the sign when only subtracting 3. Only the division by -2 reverses.

## Worked example with the book's numbers

Solve 3x + 5 = 20.
1. Remove 5 from both sides: 3x + 5 - 5 = 20 - 5, so 3x = 15.
2. Split both into 3 groups: (3x) / 3 = 15 / 3, so x = 5.
3. Reverse: 3(5) + 5 = 15 + 5 = 20, and the right side is 20.

The one-sided mistake: remove 5 from the left only to get 3x = 20, x = 20/3. Check: 3 x 20/3 + 5 = 25, not 20.

Both sides: at x = 5, 5(5) - 7 = 18 and 2(5) + 8 = 18. The gap is 3x - 15 in both forms, zero only at x = 5.

Inequality: -2x + 3 <= 11. Subtract 3: -2x <= 8. Divide by -2 and reverse: x >= -4. Test x = -4: -2(-4) + 3 = 11, and 11 <= 11 is true. Test x = -5: 13 <= 11 is false, so -5 is left out.

## When the idea stops working

- Dividing by zero is never allowed, so a step involving a variable divisor needs care.
- Testing a few values cannot prove there are no other solutions; equal treatment does that.
- Testing checks an inequality answer but is not the reason for the reversal; the reflection across zero is.
