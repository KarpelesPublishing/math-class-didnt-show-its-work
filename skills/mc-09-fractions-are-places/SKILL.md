# Chapter 9: Fractions Are Places

## The core idea

A fraction is a place on the number line. The bottom number (denominator) says how many equal steps make one whole, so each step is 1/b. The top number (numerator) says how many of those steps to take from zero. Before anything else, name the whole: a fraction of what?

Two consequences the chapter builds on:
- Counts can pass the whole. 7/4 is seven steps of one fourth; four fourths make one whole, so 7/4 = 1 3/4, and the space in a mixed number means plus.
- One place has many names. Cutting every part into n smaller parts multiplies top and bottom by n and the place does not move.

## Key equations (as the chapter writes them)

- a/b, and 1/4 + 1/4 + 1/4 = 3/4
- 4/4 = 1, and 11/4 = 8/4 + 3/4 = 2 3/4
- 2 / 4 = 1/2 (the length in meters of one piece of a 2-meter ribbon cut in 4)
- a/b = (a x n)/(b x n), for example 1/2 = (1 x 4)/(2 x 4) = 4/8

## Coaching method

1. Ask for the learner's own fraction and what it is a fraction of (a pizza, a ruler, a cup).
2. Have them predict first: "Will 7/4 be before 1, at 1, or past 1?"
3. Walk it one substitution at a time. Draw a number line, find the step size 1/b, then count steps (spaces, not marks).
4. Check with a reverse step: for a mixed number, rebuild the fourths (wholes x 4 + leftover). For a renamed fraction, divide top and bottom by n and land back on the start.
5. Ask them to say the unit out loud: "3 fourths of the ribbon" versus "1 1/2 meters".

## Common sticking points

- Counting marks instead of spaces. Say: "Count the hops, not the posts." Five spaces use six marks including 0.
- "A bigger bottom number should mean a bigger fraction." Show that more parts means smaller parts: 1/8 is shorter than 1/4.
- "Improper fractions are wrong." They are fine; the count simply passed one whole.
- Adding the same number to top and bottom to rename (2/3 to 4/5). Renaming multiplies; it does not add. Draw both and show the endpoints differ.
- Confusing the whole: 3/4 of a ribbon versus 1 1/2 meters is the same spot with two names.

## Worked example with the book's numbers

Where is 7/4, and what mixed number is it?
1. Step size: the bottom number is 4, so each step is 1/4.
2. Count 7 steps from zero: 1/4 + 1/4 + 1/4 + 1/4 + 1/4 + 1/4 + 1/4 = 7/4.
3. Group into wholes: 7 = 1 x 4 + 3, so 7/4 = 4/4 + 3/4.
4. Since 4/4 = 1, 7/4 = 1 + 3/4 = 1 3/4.
5. Reverse: 1 x 4 + 3 = 7 fourths. Same count we started with.

Renaming: 1/2 with n = 4. (1 x 4)/(2 x 4) = 4/8. Reverse: (4 / 4)/(8 / 4) = 1/2. Both end at 0.5 of the whole.

Ribbon: a 2-meter ribbon cut in 4 equal pieces. One piece is 2 / 4 = 1/2 meter. Three pieces: 3 x 1/2 = 3/2 = 1 1/2 meters, which is 3/4 of the ribbon. Check: 1 1/2 + 1/2 = 2 meters.

## When the idea stops working

- The steps must be equal; unequal parts do not give fractions of a whole.
- The whole must be named, and equal wholes must be compared. Two "halves" of different pizzas are different amounts.
- Renaming needs the same factor on top and bottom, never the same number added.
